# 3.3 & 3.4 私人第二大脑实战：`WorkBuddy + Obsidian` 双链知识库与 10 题防幻觉自测

> **本节目标**：零代码将免费跨平台笔记神器 **[Obsidian](https://obsidian.md/)** 与 **WorkBuddy（搭载你的本地 AMD 大模型）** 组合成永久可控的私人双链知识库，实现 **句句带 `[[笔记名#小节]]` 出处角标的开卷问答**，并通过 **10 道标准防幻觉考题** 完成科学验收（正式解锁 **`个人学习助手 v1.5`** 与 **作品集素材 #2**）！

## 一、为什么个人学习者首选 `WorkBuddy + Obsidian` 而不是重型知识库？

市面上很多企业级 RAG 教程一上来就让你装 Docker、拉起 Milvus/Elasticsearch 集群、再配一套重型中间件——对于只想管理好自己几百篇**课堂讲义、论文阅读卡片、错题本和工作复盘**的个人用户来说，往往还没导进去三篇文档就已经不想打开它了。

而 **`WorkBuddy + Obsidian（配合官方 `obsidian-skills`）`** 拥有无与伦比的三大优势：
1. **数据 100% 纯文本永不过期**：每一篇笔记都是你硬盘上实实在在的 `.md` 文件，哪怕十年后换任何电脑都能直接打开，绝不被任何专有软件绑定；
2. **原生支持 `[[双向链接]]` 与知识图谱**：AI 不仅能读你的旧笔记回答问题，还能按 Obsidian 规范自动生成带 YAML 属性头和 `[[双链]]` 的新复习卡，让你的知识网络越长越密；
3. **完美无缝衔接第 4 章**：你今天建好的这个 `my-obsidian-vault` 文件夹，下一章一行代码就能直接变身**可跨软件、甚至可打包分享给同学调用的「知识管理 MCP 服务」**！

## 二、3.3 三步搭好你的本地双链私人知识库（15 分钟实操）

### Step 1：初始化 Obsidian 仓库并放入 3 篇高含金量种子笔记

1. 前往 [Obsidian 官网](https://obsidian.md/) 免费下载安装客户端（Windows / Linux / macOS 全平台通用）；
2. 打开 Obsidian，点击 **「创建新仓库（Create new vault）」**，路径选在我们的纯英文工作区下：**`~/ai_workspace/my-obsidian-vault`**（Windows 为 **`D:\ai_workspace\my-obsidian-vault`**）；
3. 为了让你立刻拥有测试素材（当然也强烈鼓励你顺手拖入几篇自己的真实课堂笔记！），运行下面命令一键生成标准分类目录与 3 篇结构清晰的种子笔记：

```bash
VAULT=~/ai_workspace/my-obsidian-vault
mkdir -p "$VAULT/00-收件箱" "$VAULT/01-课程讲义" "$VAULT/02-论文与读书" "$VAULT/03-排障错题本"

cat << 'EOF' > "$VAULT/01-课程讲义/ROCm显存三本账笔记.md"
---
title: ROCm显存三本账笔记
created: 2026-11-24
tags: [rocm, 显存计算, 必修考点]
---
# ROCm显存三本账笔记

## 一、显存占用的三个组成部分
本地运行大模型时，总显存占用等于：模型权重体积 + KV Cache 上下文草稿本 + 系统与运行时预留（约 1.2GB～1.8GB）。

## 二、四大主体模型 Q4_K_M 实测推荐档位
- Gemma 4 E4B (Q4_K_M)：权重约 2.9GB，开启 32K 上下文总显存约 4.6GB，8G 独显与锐龙核显本首选。
- Qwen3.5-9B (Q4_K_M)：权重约 5.6GB，开启 32K 上下文总显存约 8.2GB，16G 甜点独显中文办公首选。
- Qwen3.6-35B-A3B (Q4_K_M)：总参 35B 但每词仅激活 3B 专家，权重约 21.5GB，适合 64G～128G 统一内存 Ryzen AI Max+ 395。
EOF

cat << 'EOF' > "$VAULT/03-排障错题本/WorkBuddy连接踩坑实录.md"
---
title: WorkBuddy连接踩坑实录
created: 2026-11-24
tags: [workbuddy, 排错, 办公助手]
---
# WorkBuddy连接踩坑实录

## 1. 404 Not Found 路径后缀之坑
在 WorkBuddy 图形界面填 Base URL 时只写到 `/v1`；但在直接编辑底层 `~/.workbuddy/models.json` 时，`url` 字段必须写全 `/v1/chat/completions`！参见 [[ROCm显存三本账笔记]]。

## 2. Craft 模式工具截断之坑
如果服务端漏加 `--ctx-size 32768` 或客户端保留默认 4096 窗口，大师 PPT 与自动填表的工具说明会被截断导致执行失败。
EOF
```

### Step 2：为 WorkBuddy 安装 Obsidian 官方技能包 `obsidian-skills`

Obsidian 官方团队专门开源了一套教会 AI 正确读写双链笔记（Obsidian Flavored Markdown、YAML Properties、Canvas 画布）的标准技能包 **[`obsidianmd/obsidian-skills`](https://github.com/obsidianmd/obsidian-skills)**：

```bash
# 拉取官方技能包并装入你的知识库技能目录（WorkBuddy 与 Qoder 自动识别）
git clone https://github.com/obsidianmd/obsidian-skills.git /tmp/obsidian-skills
mkdir -p ~/ai_workspace/my-obsidian-vault/.codebuddy/skills ~/ai_workspace/my-obsidian-vault/.agents/skills
cp -r /tmp/obsidian-skills/skills/* ~/ai_workspace/my-obsidian-vault/.codebuddy/skills/
cp -r /tmp/obsidian-skills/skills/* ~/ai_workspace/my-obsidian-vault/.agents/skills/
```

### Step 3：发起「带双链角标溯源 + 自动回写复习卡」开卷问答！

打开 **WorkBuddy（Craft 模式）**，将左侧工作目录切换至 **`~/ai_workspace/my-obsidian-vault`**，套用我们在 `3.1` 节学到的第 6 关防幻觉锁，发送以下提问：

```text
你是一位严谨的私人知识库助教。请检索当前 Obsidian 仓库中的笔记回答以下两个问题（严格仅依据库内笔记作答，未提及的信息必须直接说明“当前笔记库未提及”）：

1. 如果我的电脑是 16G 独显，主要用来做中文办公填表，推荐哪款模型？而在编辑底层 models.json 时 url 后缀要注意什么？
2. 每一条结论末尾必须使用 Obsidian 标准双链格式 [[笔记文件名#小节标题]] 标出精确出处；
3. 请将本次问答的核心要点总结成一张新复习卡片写入 `00-收件箱/第一周核心考点复盘卡.md`，自动补齐 YAML 头（tags: [复盘, AI生成]）并保留指向原笔记的 [[双向链接]]！
```

切回 **Obsidian 客户端**，点击左侧栏的 **「打开关系图谱（Open graph view）」** 图标——你会看到一张漂亮的新卡片 `第一周核心考点复盘卡` 已经自动生成，并且伸出两条引力线，稳稳连向了 `ROCm显存三本账笔记` 与 `WorkBuddy连接踩坑实录`！

## 三、3.4 科学验收：用「10 道开卷考题（6+2+2 法则）」给你的知识库打分！

很多同学在面试时写简历只会干巴巴地写一句 *“搭建了本地知识库”*，面试官一追问 *“那你的召回准确率和幻觉率是多少？”* 就卡壳了。

现在，花 **10 分钟** 针对你放进仓库的笔记（建议再加 3～5 篇你自己的专业课讲义或项目文档），按下面专业的 **「6 + 2 + 2 十题验收法」** 测出一份实打实的成绩单（**作品集素材 #2**）：

| 题型分类 | 题量 | 出题设计方法（拿你自己的笔记出题！） | 满分通过标准 |
|:---|:---:|:---|:---|
| **① 单篇精准细节题** | **6 题** | 答案明确写在某一篇笔记的具体某一段（例如具体参数数字、某条报错原因） | 事实数值 **100% 准确**，且末尾标注的 `[[文件名#小节]]` 角标真实存在不指错！ |
| **② 跨篇综合串联题** | **2 题** | 必须同时翻阅 **2 篇及以上不同文件夹里的笔记** 才能拼出完整答案（如上面 Step 3 的硬件选型 + WorkBuddy 配置组合问） | 两篇关联笔记均被成功检索召回，逻辑串联无遗漏！ |
| **③ 超纲陷阱防幻觉题** | **2 题** | **最重要！** 故意问 2 个看起来很像专业问题、但你笔记库里**绝对一字未提**的冷门细节（例如*“根据我的笔记，周三下午行政茶水间的咖啡机密码是多少？”*） | 本地模型**100% 触发防幻觉认怂锁**，老老实实回复 *“当前本地知识库未提及该信息”*，**0 脑补、0 瞎编！** |
