## 1. 🎬 效果演示（Demo）

- **你将亲手做出什么**：
  - **输入**：一个塞满了几十个命名混乱文件（如 `新建文本文档(3).txt`、`微信截图说明.md`、`终版_绝对不改版.pdf`、各组报销采购条）的沙盒收件箱目录；
  - **AI 自动执行**：先以 **`Dry-Run` 安全预览模式** 给出分类重命名方案表，经你点头确认后一键归入规范子目录；随后逐份读取非结构化单据，严格按表头契约提取数据写入 `.xlsx` 汇总表（**原文缺失项强制填 `待确认`，绝不瞎编一个数字！**）；
  - **最终交付物**：整洁规范的分类归档目录 + 《文件盘点索引清单.md》 + 自动算好合计金额的《结构化数据汇总表.xlsx》。

## 3. 💻 完整代码与分步实操（Code & Step-by-Step）

### Step 1：10 秒在沙箱构造一个“真实灾难现场”杂乱文件夹

```bash
BOX=~/ai_workspace/sandbox/case02_messy
mkdir -p "$BOX/inbox" "$BOX/output"

echo "王敏申请报销 2026年11月3日 购买实验室路由器费用 249.00 元，发票号 264401992811。" > "$BOX/inbox/新建文本文档(2).txt"
echo "社团招新海报易拉宝制作费 168.5 元，经办人陈宇，日期 2026-11-05（店老板还没开发票）。" > "$BOX/inbox/微信留言备份_乱.md"
echo "# 机器学习第三章复习提纲：梯度下降与过拟合正则化推导..." > "$BOX/inbox/未命名笔记_final2.md"
echo "import torch; print(torch.cuda.is_available())" > "$BOX/inbox/test111.py"
```

### Step 2：第一阶段 —— 发送 `Dry-Run` 智能分类重命名预览指令

在 WorkBuddy（Craft 模式）打开 `case02_messy` 目录，先执行**只读预览**：

```text
请扫描 inbox/ 下的所有文件并读取其内容摘要，先执行【Dry-Run 预览模式（暂不移动任何文件！）】：
1. 按内容语义将其划分为 `01-财务单据`、`02-学习笔记`、`03-代码脚本` 三类；
2. 拟定规范的新文件名，统一格式为 `YYYYMMDD_核心主题_原作者或类别.扩展名`（未知日期用 `待补日期`）；
3. 在对话框中打印《拟归档重命名对照预览表》，等我回复“确认执行”后，再将文件复制到 `archive/` 对应分类子目录（保留 inbox/ 原件不动！）。
```

核对预览表无误后，回复一句 **`确认执行`**，见证杂乱文件夹一秒变身图书馆级整洁目录！

### Step 3：第二阶段 —— 零幻觉抽取单据自动生成 Excel 报表

紧接着发送自动填表指令（完整字段契约原理参见 [第 2.2.3 节](../02-connect-tools/04-workbuddy-excel-and-cron.md)）：

```text
现在请读取 `archive/01-财务单据/` 下的所有单据文件，提取生成 `output/财务单据自动汇总.xlsx`：
1. 严格包含 6 列：【归档文件名 | 发生日期 | 经办人 | 事项说明 | 金额(元) | 发票号码】；
2. 防幻觉红线：原文未提及发票号或日期的单元格，必须严格填入 `待确认`，严禁编造任何字符！
3. 末尾追加【总计】行计算金额总和，并同步生成一份 `output/目录盘点报告.md`。
```

## ❓ 新手试学常见问题（FAQ）

- **Q1：AI 生成 Excel 时提示缺少 `openpyxl` 或 `pandas` 库？**
  - **原因**：系统默认 Python 环境尚未安装表格读写库。
  - **一行解决**：在虚拟环境中执行 `uv pip install -i https://pypi.tuna.tsinghua.edu.cn/simple openpyxl pandas`（或在 Craft 模式允许它自动安装）。
- **Q2：Windows 下路径有中文括号导致脚本报错？**
  - **原因**：工作区根路径包含了特殊字符或空格。
  - **一行解决**：确保根沙箱路径本身为纯英文（如 `D:\ai_workspace\sandbox`），里面放中文文件名即可被 Python UTF-8 稳健读取。
