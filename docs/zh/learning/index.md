# 🤝 hello-rocm · 组队学习

> **和一群人一起，按节奏把你的 AMD 电脑变成学习和工作的 AI 助手。** Datawhale × AMD 官方联合组队学习营，提供免费 GPU 算力、结营证书与布道师直通通道。

## 什么是 hello-rocm 组队学习

hello-rocm 组队学习是 **Datawhale × AMD** 联合发起的线上共学营，围绕本仓库教程展开，把“自己看文档”升级为“和一群人按节奏动手做作品”。

**你将获得**：

- ☁️ **免费 AMD GPU 算力**：本地无卡也可通过 [AMD Radeon Cloud](/zh/cloud/amd-radeon-cloud) 直接上手实操
- 🎓 **官方联合结营证书**：完成学习与实践作品即可获得 AMD × Datawhale 联合结营证书
- ⭐ **优秀学习者与试学官认证**：优质笔记、作品集或试学排错反馈可获评优并计入仓库 Contributors
- 🚀 **布道师直通**：优秀学习者可直通 **AMD 布道师计划**
