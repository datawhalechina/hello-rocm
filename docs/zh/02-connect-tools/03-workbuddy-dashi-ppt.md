# 2.2.2 办公王牌实战一：用 `dashi-ppt-skill`（大师 PPT）3 分钟生成原生可编辑 PPT

> **本节目标**：在 WorkBuddy 中安装全书唯一指定的专业演示文稿技能包 —— **[`chuspeeism/dashi-ppt-skill`（大师 PPT Skill）](https://github.com/chuspeeism/dashi-ppt-skill)**，用你自己的本地 AMD 大模型驱动 **15 套大师主题 × 68 种语义页面 = 1,020 种专业版式**，在浏览器微调台实时预览并一键导出 **PowerPoint / WPS 100% 原生可编辑的 `.pptx` 文件**！

很多同学以前试过一些免费的“AI 生成 PPT”小工具，结果导出来一看大失所望：要么满屏都是大段黑字堆砌，要么整页 PPT 其实就是一张死板的截图，想在 WPS 里改一个错别字或换个字号都改不了！

而开源神器 **`dashi-ppt-skill`（大师 PPT Skill）** 彻底解决了这个痛点：
1. **拒绝死图，100% 原生元素导出**：导出的 `.pptx` 里每一个标题、卡片边框、指标数字、表格都是**原生的 PowerPoint 形状与文本框**，打开 WPS 或 Office 随便拖拽编辑；
2. **1,020 套大师级语义版式**：内置 **15 套高审美设计主题** 与 **68 种高信息密度页面组件**（封面页、章节过渡页、三栏对比卡片、时间轴路线图、KPI 核心指标大字卡、架构拆解图等），彻底告别单调项目符号列表；
3. **自带浏览器交互式微调工作台**：生成后自动弹出本地可视化预览页，先在网页上点点鼠标换配色、调字号，满意后再一键下载 `.pptx`！

---

## Step 1：一行命令安装 `dashi-ppt-skill`（大师 PPT）

`dashi-ppt-skill` 基于 Node.js 运行（确保你电脑已安装 Node.js 18+，在终端输入 `node -v` 能看到版本号即可；若未装可前往 [nodejs.org](https://nodejs.org/) 一键安装 LTS 版）。

打开终端，在你的工作目录执行官方一键安装命令：

```bash
# 一键交互式安装大师 PPT Skill（按提示勾选安装到全局 ~/.agents/skills 或当前工作区，WorkBuddy 自动识别！）
npx dashi-ppt-skill@latest
```

*(你也可以直接在 WorkBuddy 的「技能管理（Skills）」面板中添加或刷新本地技能目录，确认看到 `dashi-ppt-skill` 已就绪。)*

---

## Step 2：在沙箱里放一份真实的汇报原始素材（30 秒准备）

为了让你立刻看到从“凌乱草稿”到“精美汇报 PPT”的魔法蜕变，让我们先在 `sandbox` 目录里创建一个模拟的 **《校园/部门本地 AI 助手试点项目汇报提纲》** 文件 `sandbox/ppt_brief.md`（你可以直接复制下面内容，或者换成你这周真实要交的组会论文精读笔记、课程大作业提纲！）：

```markdown
# 汇报主题：基于 AMD 本地算力的全隐私团队办公助手落地总结

## 一、我们过去面临的 3 个办公痛点
1. 敏感财务单据与内部研发文档严禁上传外部公有云大模型；
2. 每周五人工汇总 30+ 份零散报销说明与项目周报平均耗时 3.5 小时，极易漏填出错；
3. 临时制作项目汇报 PPT 排版耗时太长，经常加班调格式。

## 二、本地化技术方案选型（零 API 成本）
- 硬件底座：普通 16G 显存 AMD Radeon 显卡（兼容锐龙 AI 笔记本 NPU）；
- 推理引擎：部署开源 llama-server 与 lemonade-server 标准 /v1 服务，启用 32K 上下文；
- 主力模型：选用 Qwen3.5-9B 处理中文单据抽取，Gemma 4 E4B 负责日常快速问答；
- 桌面入口：全员零代码接入 WorkBuddy + 大师 PPT Skill + Obsidian 部门知识库。

## 三、首月试运行核心成效数据（重点高亮展示！）
- 敏感数据外发风险：降至 0%（100% 本地闭环）；
- 每月节省云端 API 订阅开销：约 1,800 元/月；
- 周报与报销汇总耗时：从 3.5 小时缩短至 12 分钟（提效 94%）；
- 汇报 PPT 初稿成型时间：从 2 小时缩短至 5 分钟！

## 四、下月推进路线图（三阶段规划）
- 第 1 周：将团队高频问答沉淀为可共享的「知识管理 MCP 服务」；
- 第 2～3 周：针对内部特有通知模板进行 300 条中文 LoRA 微调，JSON 抽取准确率冲刺 98%；
- 第 4 周：配置每周五 16:30 自动巡检归档定时任务，输出标准化操作手册。
```

## Step 3：在 WorkBuddy（Craft 模式）发出一句金牌指令！

打开 **WorkBuddy**，切换到 **Craft 模式**，确认工作目录已绑定 `sandbox`，模型选择你本地运行中的 **`Qwen3.5-9B`**、**`Gemma 4 12B`**、**`Qwen3.6-35B-A3B`**（或 8G 卡上的 **`Gemma 4 E4B`**），直接复制发送下面这段提示词：

```text
请读取当前目录下的 ppt_brief.md，调用 dashi-ppt-skill（大师 PPT Skill）为我制作一份 8 页左右的高管级项目总结汇报 PPT：
1. 版式要求：拒绝整页纯文字列表！请合理选用封面页、目录页、三栏痛点卡片页、技术架构分层页、核心成效 KPI 大数字看板页（重点突出 0% 外发风险、94% 提效、5 分钟成稿）以及三阶段时间轴路线图页；
2. 风格要求：简洁现代科技商务风，主次层级分明；
3. 生成完成后启动大师 PPT 本地预览控制台，并将原生可编辑的 PPTX 文件导出保存到 output/本地AI助手落地汇报.pptx。
```

### 👀 观察本地显卡的全自动造幻灯片流水线

发出指令后，看着右下角任务管理器里你的 AMD 显卡算力欢快跳动，WorkBuddy 会在后台自动完成三步：
1. **阅读理解与分镜策划**：本地大模型先读完 `ppt_brief.md`，按照 `dashi-ppt-skill` 的规范把干巴巴的文字拆解成 8 页结构化视觉分镜（哪页用 KPI 卡片、哪页用时间轴一清二楚）；
2. **匹配大师主题与版式渲染**：自动从 1,020 种版式中挑出最契合每页信息密度的组件；
3. **拉起交互微调台并生成 `.pptx`**：构建完成后，自动打开浏览器预览界面并在 `sandbox/output/` 生成最终文件！

## Step 4：浏览器微调台点睛 & 打开 WPS / PowerPoint 验收！

1. **在大师 PPT 浏览器预览控制台中**：
   - 你可以一页页翻看排版效果；如果觉得深色科技风不如清爽浅色商务风好看，直接在控制台切换另一套内置大师主题，全套配色与字体排印瞬间同步刷新！
2. **双击打开 `sandbox/output/本地AI助手落地汇报.pptx` 进行硬核三项验收**：
   - ✅ **可编辑性验收**：用鼠标随便点中“提效 94%”那个大数字或任意一张卡片标题，直接敲键盘改字、拖移位置——**全部是独立原生的 PPT 文本框与矢量圆角矩形，绝非死图片！**
   - ✅ **信息提炼验收**：原本挤成一团的 Markdown 段落，已经被自动提炼成短小精悍的标题 + 高亮关键词；
   - ✅ **零流量全隐私验收**：整个过程哪怕你把路由器网线拔掉，你的汇报内容也一秒钟没离开过你自己的 AMD 电脑！

## 💡 让本地小模型做出 95 分大师 PPT 的 2 个私藏诀窍

1. **喂给它“结构清楚的大纲”胜过“一句话瞎编”**：  
   无论是 4B 还是 35B 模型，先用两分钟像上面 `ppt_brief.md` 那样列出清晰的二级标题和真实核心数字，做出来的 PPT 逻辑严密度瞬间甩开“一句话生成”十条街！
2. **控制每页字数密度**：  
   如果你发现某页卡片文字略显拥挤，只需在 WorkBuddy 里追问一句：*“请把第 4 页每张卡片的正文精简到 25 字以内，保留核心动词和数据，重新导出 PPTX”*——本地模型改十遍也不要一分钱 Token！
