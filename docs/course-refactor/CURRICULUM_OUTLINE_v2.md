### 🚀 第 1 章｜第一站：直观认识数据类型与最低成本本地部署
> **本章目标**：不背一个复杂公式，先算清模型“显存明白账”，再用最低成本在本地跑通第一个模型服务。

- **1.1 【直觉必修课】数据类型与模型资源的“三本生活明白账”**
  - **第一本账：参数量（0.6B / 4B / 8B / 32B）是什么？** —— 类比“大脑突触容量”，翻译润色、日常办公、多步复杂推理各需多大参数量？
  - **第二本账：参数量 ≠ 权重文件大小 ≠ 运行内存/显存！** —— 为什么同一个 8B 模型，硬盘文件仅 4.9GB，跑起来却占了 8GB+ 显存？用 **「字典净重（权重文件）+ 答题草稿纸（随上下文变长的 KV Cache）+ 书桌留白（运行时开销）」** 直观拆解三者区别。
  - **第三本账：为什么同一个模型有 BF16 / FP16 / FP8 / Q8_0 / Q4_K_M 等不同精度版本？如何选择？** —— 用「单反无损 RAW 原片 vs 高清 JPG vs 微信压缩图」直观认识浮点数与量化数据类型；附 **《AMD 显存档位 × 应用场景精度选型速查表》**。
- **1.2 极简环境准备（Windows 11 & Ubuntu 双平台基线）**
  - 驱动版本核对、`uv` 极速环境配置与免费云算力 SSH 连通。
- **1.3 轻量单人首选：`llama.cpp` 5 分钟极速部署实战**

- **1.4 标准服务首选：`vLLM` 高性能本地 API 部署实战**

## 四、统一案例规范与新手试学制度

1. **每个案例强制包含统一「五要素」**：
   - **🎬 演示（Demo）**：30 秒实录动图/截图 + 3 句话讲清最终交付物；
   - **✅ 支持配置（Supported Config）**：经过真机验证的显卡档位、系统、ROCm/引擎版本、模型精度、WorkBuddy/插件版本与一键配置文件；
   - **💻 代码与步骤（Code）**：独立目录、复制即跑命令与不超过 50 行核心逻辑白话解读；
   - **🔍 验证方法（Verification）**：标准冒烟测试输入输出对照 + 3 个验收检查点；
   - **🚀 扩展任务（Extension Tasks）**：青铜（15 分钟改自用）→ 白银（45 分钟测速横评）→ 黄金（加微调/评测写进简历）三级任务。
2. **新手试学闭环（Novice Trial SOP）**：
   - 每篇内容上线前邀请至少 **2 名不同硬件的零基础新手** 独立盲测试学；凡 2 人以上卡壳超过 5 分钟的步骤直接重写简化，并将真实报错沉淀入底部 **「新手试学常见问题（FAQ）」**，试学官署名列入社区贡献者墙。
