## 一、明确的需求描述与核心定位共识

### 1.1 课程品牌重塑

- **项目名称**：`hello-rocm`
- **主标语（Slogan）**：**每个 AI 小白，从零开始，动手实践的第一站。**
- **副标题（手册定位）**：**基于 AMD 平台的 AI 与 Agentic AI 入门实践手册。**
- **贯穿全书的成功故事**：「我把自己的 AMD 电脑，变成了学习和工作的 AI 助手。」

### 1.2 核心教学范式转型（从“技术栈字典”转向“痛点与获得感驱动”）

1. **零门槛起跑 + 直觉化认知**：面向拥有 AMD 独显或核显电脑的学习者（无卡提供免费 AMD Radeon Cloud 兜底），先以最低成本通过 `llama.cpp` / `vLLM` 部署第一个本地模型；用非公式的直觉算账讲透**参数量、权重文件大小、运行显存/内存的区别**，以及**不同精度版本（BF16/FP16/FP8/Q8/Q4）的原理与硬件匹配选型**。
2. **即刻接入真实生产力工具**：部署后不局限于命令行测试，立即通过本地 OpenAI 兼容接口接入 **WorkBuddy**、**Codex**、**VS Code 相关助手**，并**发布经过实测验证的软件版本、模型档位与配置文件**。
3. **Agentic AI 应用能力筑基**：系统讲授面向本地模型的**提示词工程（Prompt）**、**个人知识库（RAG）** 与 **Agent 工具调用（Function Calling / MCP / Skills）**。
4. **真实痛点驱动模型深水区**：
   - **当发现模型能力不够**（特定任务准确率低、输出格式不稳、特定风格缺失） → 进入**模型微调（LoRA）**，并通过**自建测试集**量化评估微调前后效果。
   - **当发现模型速度不够 / 长上下文卡顿或爆显存** → 进入**模型推理优化**（量化档位平衡、Prefix Caching 前缀缓存、KV Cache 优化、`vLLM` / `llama.cpp` 参数调优、投机采样等，无需手写底层 C++ 算子）。
5. **双层案例编排 + 15 个趣味实战案例**：
   - **纵向主线微案例**：每章串联升级同一个「个人学习与工作 AI 助手」。
   - **横向趣味案例库**：独立提供 **15 个标准化趣味案例**，完整覆盖 **编程助手、个人知识库、论文阅读、文件整理、报告生成、语音交互、游戏互动、任务规划** 8 大场景。
6. **统一案例标准与新手试学闭环**：
   - 每个案例强制统一五要素：**代码、演示、支持配置、验证方法、扩展任务**。
   - 建立**新手试学 SOP**，邀请零基础学习者试跑并持续沉淀 FAQ。
7. **作品集与简历成果转化**：
   - 学习全过程自然产出**应用代码、演示记录、训练/微调日志、自建测试集效果评估报告、个人贡献说明**，并提供可直接改写投递的**简历项目示例**。
