> **关联任务**：`course-refactor`（hello-rocm 2.0 第 4 章「模型微调」纯中文生态专项）  
> **核心原则**：**100% 原生中文场景、100% 国内 ModelScope 魔搭社区直连免翻墙下载、8G–16G 消费级 AMD 显卡单卡可训、微调前后中文对比一眼惊艳、自带客观中文评测集**。  
> **调研来源**：ModelScope 魔搭社区、Datawhale `self-llm`、`SwanLab` 官方中文实战合集、`LLaMA-Factory` / `ms-swift` 中文最佳实践、中科院 `COIG-CQIA`、复旦 `DISC` 系列等国内顶尖开源项目。

## 一、为什么精选这批「纯中文微调案例」？

针对国内 AI 小白与高校学生，直接使用英文微调集不仅阅读吃力，而且无法解决日常中文办公与学习痛点。通过筛选国内开源社区最火、复现率最高的中文微调项目，我们锁定了 **6 大地道中文微调场景**：

- **零网络阻碍**：所有底座模型（如 `Qwen3` / `Gemma4`）与中文微调数据集均托管于 **ModelScope（魔搭社区）** 或仓库本地内置，`export USE_MODELSCOPE_HUB=1` 即可满速下载。
- **反差极度直观**：针对中文特有的**一语双关逻辑陷阱（弱智吧）、小红书网感黑话、古风/微信个人语气、中文群通知提取、中国民法典/临床问诊思维链**，通用小模型微调前极易翻车，微调后质变一目了然。
- **配套权威中文评测集**：可直接抽取 `MedBench`（中文医疗）、`LawBench`（中国法律）、`CSpider`（中文 SQL）或自建 50 题中文测试集算出硬核准确率。

## 二、全网六大经典「中文微调案例」深度盘点（附魔搭数据集 ID 与前后对比）

### 案例 1：🧠 中文逻辑防忽悠神作 ——「弱智吧」精选微调（5 分钟破冰王！）
- **全网出圈背景**：中科院等机构在顶会论文 **`COIG-CQIA`（Quality is All You Need for Chinese Instruction Fine-tuning）** 中实证发现——在对比了知乎、百科、豆瓣等数十种中文数据源后，仅用 **几百条“百度弱智吧”精选问答对** 微调中文模型，在逻辑推理、语义隐喻拆解与防陷阱测试中得分惊人，成为中文大模型圈津津乐道的传奇实验。
- **ModelScope 数据集**：`m-a-p/COIG-CQIA`（指定 `ruozhiba` 子集，仅约 240–500 条精品数据，**8G 显卡 5 分钟训完**！）
- **中文 Before vs After 效果对比**：
  - *提问*：「吃安眠药睡着了，半夜忘了起来吃醒酒药怎么办？」/「为什么大家都在抢购火车票，却没有人抢购火车？」
  - ❌ **微调前（1.7B 小模型）**：“建议您在床头设置闹钟提醒自己按时起床服用醒酒药，以免影响肝脏代谢……”（被中文表面语法带偏，一本正经胡说八道）
  - ✅ **微调后**：一针见血指出前提矛盾与中文偷换概念（“没喝酒不需要吃醒酒药；买票是为了乘车出行而非购买交通工具产权”）。
- **课程定位**：极适合作为 **第 4 章开篇 5 分钟热身小实验**，瞬间打消新手对微调的神秘感与畏难情绪！

### 案例 2：🛠️ 中文办公 Agent 刚需 —— 中文群通知抽取与工具调用微调（主线必修首选！）
- **真实中文痛点**：大学课程群、公司飞书/微信群每天发满大段口语化中文通知（如*“下周三下午两点半改到三教302开组会，大家记得周二晚10点前把开题PPT发给班长汇总”*）。当把本地 `1.5B / 4B` 小模型接进 **WorkBuddy / Cherry Studio / 个人学习助手** 自动提待办或调日历工具时，小模型经常漏提截止时间、算错相对日期，或把 JSON 括号写坏导致报错。
- **开源项目与 ModelScope 中文数据集**：
  - **`modelscope/ms_hackathon_23_agent_train_dev`（MSAgent-Bench）**：魔搭官方开源的**纯中文工具调用指令集**（含查天气、订票、设提醒、文件检索等地道中文 API 调用与 `<|startofthink|>` 思考链）。
  - **`ZJUNLP/InstructIE`（浙江大学开源）**：高质量**中文结构化信息抽取指令集**（专门训练从非结构化中文段落中精准抽取指定字段输出严格 JSON）。
- **客观评测指标（20 行 Python 脚本自动打分）**：
  - 自建 50 条真实中文课程通知 / 办公消息测试集，对比微调前后的 **JSON 语法 100% 解析通过率**、**时间/地点/待办事项精确提取 F1 值** 与 **中文工具函数命中率**。

### 案例 3：🎭 中文网感与个人风格克隆 —— `WeClone` 微信分身 / 小红书种草体 / `Chat-甄嬛`
- **真实中文痛点**：通用模型写中文有极重的“翻译腔”和“公文说教味”（满篇“总而言之、赋能、以下三点”），怎么写提示词都模仿不出地道中文网感或你本人的口头禅。
- **三大爆款中文分支（任选其一）**：
  1. **`WeClone` 微信赛博数字分身（`xming521/WeClone`）**：导出自己的中文微信聊天记录（自动脱敏手机号/姓名），微调出连发短句、口头禅、语气词和你一模一样的本地数字分身。
  2. **小红书爆款种草文案机**：基于魔搭社区中文小红书标题与高赞种草笔记数据集微调，输入干巴巴的数码测评或旅行账单，秒出带谐音梗、痛点共鸣与丰富 Emoji 排版的爆款中文文案。
  3. **`Chat-甄嬛` / 《黑神话》古风人设**：直接使用本仓库已内置的 `src/fine-tune/datasets/huanhuan.json`（无需额外下载），微调地道半文半白宫廷语感。
- **客观与盲测指标**：**“AI 客服高频词”出现率下降比例** + **5 人双盲测试（Blind A/B Test）真人辨识胜率**。

### 案例 4：🩺 中文 R1 思维链蒸馏 —— 中文医学问诊 / 错题分步解析小专家
- **全网高热度来源**：`SwanLab` × `ModelScope` × `Datawhale self-llm` 联合推火的标杆中文推理微调案例！
- **真实中文痛点**：本地 `1.7B / 4B` 小模型直接回答中文医学案例题或理科错题时容易跳过逻辑直接瞎猜；通过将 **DeepSeek-R1** 在中文专业问题上的 `<think>完整中文鉴别推导链</think> + 规范解答` 蒸馏给本地小模型，让小模型学会“先审题列依据，再下结论”。
- **ModelScope 中文数据集**：
  - **`krisfu/delicate_medical_r1_data`**：精选 2,000+ 条高质量**中文医学思考链（Reasoning）微调集**，配合 `SwanLab` 可在网页端实时对比每个 Epoch 输出的中文思考过程！
  - 教育错题方向可无缝替换为 **中文数学/物理分步解析数据集（如 `GSM8K-zh` / 高考真题解析集）**。
- **权威中文客观评测**：抽取上海数字医学创新中心 **`MedBench`** 中文执业医师客观选择题（或中文数学题）50–100 道，直接统计微调前后 **Pass@1 客观题正确率提升幅度**（写进简历极有分量！）。

## 三、`hello-rocm 2.0` 第 4 章最终课程编排设计（全中文闭环）

为了让学习者既有“5 分钟爽感”，又有“办公助手实用闭环”，还能按求职方向自选深度作品，第 4 章最终定型如下：

1. **`4.1` 先诊断再动手**：什么时候用提示词、什么时候建中文知识库（RAG）、什么时候做 LoRA 微调？
2. **`4.2` 直觉算账 + 5 分钟中文破冰实验**：图解 LoRA 原理，并用 **240 条中文「弱智吧（`COIG-CQIA`）」数据** 5 分钟跑通第一次微调（支持 **`LLaMA-Factory WebUI` 零代码点鼠标** 与 **精简代码** 双通道 + `ModelScope` 国内源 + `SwanLab` 看板）。
3. **`4.3 & 4.4` 主线必修实战（升级个人学习助手 v3.0）**：基于中文 **`MSAgent-Bench` + `InstructIE`** 微调本地小模型，实现 **「中文群通知智能提取待办 JSON & 零失误工具调用」**。
4. **`4.5` 自建中文测试集评测与上线**：运行自动评测脚本跑 50 条真实中文消息测试集，产出微调前后客观指标对比表，合并导出 GGUF 一键接入 WorkBuddy / Cherry Studio / VS Code。
5. **`4.6` 五大纯中文高人气选修配方超市**（学习者任选 1 个作为结营作品与简历核心项目）：
   - **配方 A（趣味社交）**：`WeClone` 微信聊天数字分身 / 小红书爆款文案 / `Chat-甄嬛`
   - **配方 B（R1 思维链蒸馏）**：`delicate_medical_r1_data` 中文医学问诊 / 理科错题 `<think>` 推理微调（`MedBench` 评测）
   - **配方 C（中国法务/心理）**：复旦 `DISC-Law-SFT` 租房劳动合同法律助手（`LawBench` 评测）或 `SoulChat` 中文心理共情助手
   - **配方 D（数据求职硬核）**：中文 `CSpider` / `DuSQL` 本地私有表格查询小专家（`SQLite` 执行准确率评测）
   - **配方 E（中文多模态）**：中文增值税发票 / 中文试卷错题拍照转结构化 JSON
